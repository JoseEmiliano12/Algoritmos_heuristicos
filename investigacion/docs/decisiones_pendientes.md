# Decisiones pendientes

Las opciones anteriores se conservan como antecedentes. Ninguna de las siguientes elecciones está aprobada por el hecho de aparecer en un documento.

| Decisión | Información necesaria | Estado |
|---|---|---|
| Lenguaje y herramientas de programación | Conocimientos del equipo y ejecución de un mismo ejemplo | Pendiente |
| Forma de guardar el grafo y las rutas | Formato real de los archivos y pruebas pequeñas | Pendiente |
| Regla para puntuar las rutas | Utilidad para orientar la búsqueda y tratamiento de conexiones inexistentes | Pendiente |
| Comprobación de ciclos | Todas las reglas de validez y ejemplos que deben fallar | Pendiente |
| Versión de colonia de abejas | Nombre, fuente y pasos del método elegido | Pendiente |
| Adaptaciones de DE y PSO | Comparación de opciones respaldadas por fuentes | Pendiente |
| Datos que recibe y devuelve cada programa | Prueba conjunta y necesidades de comparación | Pendiente |
| Precisión, recall y F1 | Definición aplicable y aclaración del profesor | Pendiente |
| Grafos, límites y repeticiones | Pruebas iniciales y tiempo disponible | Pendiente |
| Herramienta para redactar el informe | Acceso y capacidad de uso de todos | Pendiente |
| Responsable de GA y demás tareas de programación | Estimación de esfuerzo y dependencias | Pendiente |
