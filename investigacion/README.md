# Investigación del ciclo hamiltoniano

Esta carpeta organiza el aprendizaje de un equipo de cinco integrantes antes de programar los seis algoritmos de la práctica. Está preparada para trabajar con Codex y guardar los avances en GitHub.

**Prioridad actual:** comprender el problema, investigar cada método y explicar las decisiones. El lenguaje, las herramientas y el reparto final de programación se decidirán después de revisar las investigaciones.

## Primeros pasos

1. Lean [la práctica original](referencias/practica.pdf) y el [plan de organización](docs/plan_organizacion.md).
2. Completen juntos [los fundamentos y el taller del algoritmo genético](trabajo_comun/fundamentos_y_ga.md).
3. Asignen nombres y fechas en [el seguimiento del equipo](docs/seguimiento.md).
4. Cada integrante abre su guía de la tabla siguiente y utiliza el prompt incluido.
5. Guarden la investigación en `ficha.md`, las referencias en `fuentes.md` y los comentarios del compañero en `revision.md`, dentro de la carpeta correspondiente.
6. Revisen los resultados antes de decidir cómo programar. Registren los acuerdos en [decisiones pendientes](docs/decisiones_pendientes.md).

## Cómo usar esta carpeta con Codex

Abre el repositorio o esta carpeta como área de trabajo. Si abres una sesión desde otro lugar, pide expresamente que lea el archivo `AGENTS.md` de esta carpeta. Las reglas comunes están en [AGENTS.md](AGENTS.md); el tema concreto se indica con el prompt de cada guía.

Las instrucciones no comienzan por sí solas las cinco investigaciones. Cada integrante inicia su propia conversación con su prompt y responde las preguntas de comprensión. Codex puede ayudar a investigar y escribir, pero la explicación personal debe completarla el estudiante y no debe inventarse como si ya hubiera sido revisada.

No se necesita instalar bibliotecas ni ejecutar programas de los algoritmos para empezar. Las guías tienen rutas relativas para que funcionen cuando la carpeta se copie o descargue.
